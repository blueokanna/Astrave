# 桌面客户端

在「配置」中打开 TOML 文件，校验并保存，然后在「概览」中连接。连接卡显示客户端状态和配置文件中的传输参数。连接期间手动保存配置后，概览会提示等待重载。点击提示进入配置页，选择「重载已保存的配置」。

隧道列表按入站流量的方向排列，从映射端点指向本地服务。服务器确认分配后，行内显示可复制的实际端点。自动分配的端口在收到结果前显示为「自动」。「活动日志」显示最近 500 条记录。在「证书」中添加 DNS 服务商后即可申请证书。
